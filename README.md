# AQCWS GitHub Pages Site

Files for the official website of **Applied Quantum Computing Winter School 2027**.

## Upload to GitHub

Upload all files in this folder to the repository:

`aqcws/aqcws.github.io`

Then go to:

**Settings → Pages**

and choose:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

The site will appear at:

https://aqcws.github.io
